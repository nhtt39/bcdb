Bài 2: Git Merge Conflict

Thực hành tạo và xử lý xung đột khi gộp nhánh

🎯 Mục tiêu

  • Tạo mới và di chuyển giữa các nhánh Git.
  • Tạo ra Merge Conflict một cách có chủ đích.
  • Xử lý xung đột thủ công trong file.
  • Thực hiện Merge Commit.
  • Hiểu cơ chế gộp 3-Way Merge.

🌿 Quy trình thực hiện

1. Tạo branch feature-update

git switch main
git pull origin main

git switch -c feature-update

2. Cập nhật README trên feature-update

git add README.md
git commit -m "feat: update README on feature branch"

3. Quay lại main

git switch main

4. Tạo thay đổi trên main

git add README.md
git commit -m "docs: update README on main"

5. Merge feature-update

git merge feature-update

⚠️ Merge Conflict

Khi hai branch cùng thay đổi một dòng trong README.md, Git có thể không tự quyết định phiên bản nào được giữ lại.

Git sẽ đánh dấu vùng xung đột: 
<<<<<<<< HEAD
Đây là nội dung được thay đổi trên main.
=======
Đây là nội dung được thay đổi trên feature-update.
>>>>>>> feature-update

🛠️ Xử lý Conflict

Người lập trình cần mở file

Sau khi sửa, phải xóa toàn bộ các ký hiệu: 
=======
        

git add README.md
git commit -m "merge: resolve conflict between main and feature-update"
✓ Merge Conflict đã được xử lý thành công!

📊 Kiểm tra lịch sử Git

git log --graph --oneline --all

feature-update được tách ra từ main và sau đó được gộp trở lại bằng một Merge Commit. 

*   abc1234 merge: resolve conflict
| * def5678 feat: update README on feature branch
* | ghi9012 docs: update README on main
|/
* jkl3456 initial commit

🔀 3-Way Merge

Merge Commit có hai commit cha:

  • Commit cuối của branch main.
  • Commit cuối của branch feature-update.

Git sử dụng commit chung ban đầu làm cơ sở để so sánh thay đổi của hai branch và xác định vùng xung đột. 

             feature-update
                    |
                    v
             Feature Commit
                  /     \
                 /       \
        Initial Commit   Merge Commit
                 \       /
                  \     /
                 Main Commit
                    |
                   main
